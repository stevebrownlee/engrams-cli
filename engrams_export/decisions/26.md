description: "Talk concept: inferred facts (Bob is a Teacher) should be materialized with provenance, not recomputed forever. Engrams already has the OWL-style architecture: context_links.origin stamps manual vs derived, graph rebuild regenerates derived edges idempotently. Approved 2026-08-02 with defaults: (1) InverseEdgeSource first (materialize declared inverse pairs like superseded_by/depended_on_by so consumers never need to know asserted direction); TransitiveSource deferred until rec-1 runtime traversal profiles hot. (2) Derived inverse edges appear in link list/analytics labeled origin:derived — acceptable; no manual-only default filter. (3) Inverses materialized only for canonical rels; free-form rels skipped (no declared inverse name). (4) Materialized inference stays inverse-only for now. Safety invariant: derived edges must be regenerable — inference bugs are fixed by fixing the source and rebuilding, never corrupting asserted knowledge. Export can distinguish asserted vs inferred knowledge."
