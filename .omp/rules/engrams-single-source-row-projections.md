# Single-Source Row Projections

Never hand-type a table's SELECT column list. SELECTs must be built from the shared projection constant (crate::models::DECISION_COLS / decision_cols_qualified()) and rows parsed by name (row.get("col")) so a new column is a one-line change, not a 13-file index renumber.
